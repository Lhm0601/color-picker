# 图片色号提取 & 对比度检查

拖入一张图，取色号、抓主色、查文字够不够清楚。

在线使用：https://lhm0601.github.io/color-picker/

## 功能

- 拖拽 / 点击上传，或 **Ctrl+V 直接粘贴截图**
- 鼠标悬停实时显示色号 + **放大镜取色**
- 点击存色（最多 8 个），复制 HEX / RGB / HSL
- **主色自动提取**：按像素占比给 Top 8 并标注百分比
- 复制整组颜色为 **CSS 变量**
- **WCAG 对比度判定**：正文 AA / AAA、大字 AA / AAA 四档 + 实时预览
- 前景/背景一键对调、从已取颜色里自动找最佳搭配

## 特点

- **单文件、零依赖、无后端**：打开即用，断网也能用
- **图片不上传**：全部在浏览器本地用 Canvas 处理
- 只用键盘也能操作（放大镜支持方向键 + Shift 大跨度）

## 本地运行

浏览器直接打开 `index.html`。
